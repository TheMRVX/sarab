# Support and questions

Sarab is a community-maintained Windows location-testing project; there is no guaranteed response time, paid support agreement or published direct support email.

- **Questions and usage discussion:** use [GitHub Discussions](https://github.com/TheMRVX/sarab/discussions) if available, after consulting the [usage guide](docs/USAGE.md).
- **Reproducible bugs:** search or open a [GitHub Issue](https://github.com/TheMRVX/sarab/issues/new/choose), using the bug-report template.
- **Feature proposals:** open a feature-request issue describing the problem and expected behavior.
- **Building and signing:** see [BUILDING.md](docs/BUILDING.md) and [INSTALLATION.md](docs/INSTALLATION.md).
- **Security issues:** follow [SECURITY.md](SECURITY.md) instead of opening a public thread.

When requesting help, include the Sarab version, Windows edition/build, mode (advanced/simple), exact commands, expected behavior and redacted diagnostics. Never share `.session_token`, BitLocker recovery keys or private certificates/keys.

For usage risks or policy questions about other services, refer to the relevant service provider's rules. Maintainers cannot guarantee that third-party applications will accept simulated coordinates.
